# Benchmarks

This directory holds two different kinds of benchmark.

## `contamination/`: protected evaluation sets

Evaluation material that training data must not contain, checked by the contamination stage
([methodology](../docs/methodology/contamination.md)).

| Path | Content | Committed? |
| :--- | :--- | :--- |
| `contamination/registry.yaml` | Registry of benchmarks, fields to protect, licenses | yes |
| `contamination/custom/demo_math.jsonl`, `demo_code.jsonl` | Synthetic CC0 demo sets generated by `dataforge.synthetic.benchmarks` | yes |
| `contamination/gsm8k/`, `humaneval/`, `mbpp/` | Optional local copies of public benchmarks, fetched manually | only the READMEs |

DataForge never downloads benchmark material. Public benchmark files are fetched by an
operator under their licenses (see each directory's README) and are excluded from Git by
`.gitignore`. Benchmarks marked `required: false` that are not present are reported as "not
available locally". Each benchmark file's SHA-256 is part of the pipeline fingerprint, so adding
or updating one produces a new dataset version.

## `performance/`: throughput and memory benchmarks

`performance/run.py` measures CPU throughput and memory on synthetic data (nothing is
downloaded):

```bash
uv run python benchmarks/performance/run.py exact-dedup --documents 200000
uv run python benchmarks/performance/run.py near-dedup --documents 50000
uv run python benchmarks/performance/run.py quality --documents 50000
uv run python benchmarks/performance/run.py parquet-write --documents 50000
uv run python benchmarks/performance/run.py pipeline --scale 5
uv run python benchmarks/performance/run.py streaming-memory --gigabytes 17
uv run python benchmarks/performance/run.py all --quick --output reports/benchmarks.json
```

Each result records the machine, Python and library versions, input size, wall time,
throughput, and memory. Results are appended to `performance/results/<name>.json`, and
`performance/results/RESULTS.md` is regenerated from those files, so it contains only measured
numbers. The headline figures are summarized in the
[README measured results](../README.md#measured-results).

Benchmarks run on commodity CPUs and demonstrate predictable throughput and bounded memory;
they make no claim about internet-scale processing.
