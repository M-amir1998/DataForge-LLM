## Architecture

A layered Python package (`src/dataforge/`): the CLI (`cli/`) calls the application layer
(`pipelines/`: runner, segment executor, stage DAG, stages), which drives the domain modules
(`domain/`, `parsing/`, `normalization/`, `dedup/`, `privacy/`, `licensing/`, `quality/`,
`contamination/`, `classification/`, `mixtures/`, `splitting/`, `tokenization/`) through ports
with local adapters (`sources/`, `ingestion/`, `storage/`, `sharding/`). Provenance,
validation, reporting, and telemetry (`provenance/`, `validation/`, `reporting/`,
`telemetry/`) are separate modules. Arrow and Parquet hold the canonical schema; DuckDB runs validation,
inspection, and SQL; Polars runs lazy audit analytics; NumPy vectorizes MinHash, LSH, and
mixture selection. Details: [docs/architecture/overview.md](docs/architecture/overview.md).

## Implemented stages

| Stage | Kind | Notes |
| :--- | :--- | :--- |
| Source registry and acquisition | source | Local text, JSONL, JSON, CSV, Parquet, gzip; zip/tar streamed without extraction; code trees; Hugging Face streaming (optional); synthetic |
| Normalization | streaming | Unicode NFC, control and zero-width characters, whitespace, code-aware |
| Parsing and format detection | ingestion | Plain text, Markdown, HTML, code; MIME-based parser registry |
| Language identification | streaming | Built-in detector; optional `py3langid` adapter |
| Exact deduplication | barrier | xxh3-128 of normalized content; `keep_first`, `keep_longest`, `keep_highest_quality` |
| Paragraph deduplication | streaming | Bloom filter with snapshot/resume |
| Near deduplication | barrier | Word 5-gram MinHash (128 permutations), recall-constrained LSH, union-find clusters, deterministic representatives |
| PII filtering | streaming | Email, phone, payment card (Luhn), IBAN (mod-97), IP, US SSN; detect / redact / drop |
| Secret filtering | streaming | 12 credential types including private keys and high-entropy assignments |
| License filtering | streaming | SPDX normalization, never inferred; unknown rejected by default |
| Quality scoring | streaming | 15 signals, `all_required` or `min_score`, learned-model plug-in |
| Contamination detection | streaming | Exact, normalized substring, n-gram containment, MinHash; evidence as offsets and hashes |
| Domain classification | streaming | Rule-based (keywords, URLs, content kind) |
| Mixture builder | barrier | Documents, bytes, or tokens; deterministic seeded-hash selection |
| Group-aware split | streaming | Hash, source, domain, or time; duplicate groups never span splits |
| Token and length analysis | streaming | Character, word, or Hugging Face tokenizer counts |
| Sharding | output | Size-bounded Parquet (zstd) or zstd JSONL, Hugging Face naming |
| Manifest, provenance, validation | output | Schema-versioned manifest; nine integrity checks before atomic publish |
| Reports | output | Markdown report, dataset card, SVG charts, removal audit log, attribution by source |

## Known limitations

- Single-process execution; the scale-out design is documented, not implemented.
- Heuristic quality, language, and domain filters; accuracy is measured only on synthetic,
  planted phenomena.
- Pattern-based PII detection misses names and addresses.
- Exact deduplication keeps a fixed-size key per document in memory.
- Public benchmarks (GSM8K, HumanEval, MBPP) must be added locally by hand; paraphrased leaks
  are only partly caught.
- Token counts are character-based estimates unless a tokenizer is configured.
- Object-storage publishing (`FsspecStorage`) is implemented but not selectable from the
  configuration; no S3-compatible server ships with the Compose stack because MinIO's public
  images could not be pulled.
